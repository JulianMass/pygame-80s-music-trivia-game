Interactive trivia game inspired by quiz-style applications, developed using Pygame. The game features multiple menus (Play, Settings, Player Rankings, Question Rankings, Add Questions, Exit), a scoring and lives system, power-ups to assist gameplay, and different difficulties which modify the amount of points scored and substracted, time remaining and available lives. Players answer multiple-choice questions about 80s music, earning points for correct answers and losing lives for incorrect ones. The application also includes sound effects, background music, and a persistent leaderboard where player scores are stored and displayed.
